🌤 Weather App
A beautiful and responsive Weather App built with Flutter, providing real-time weather updates, forecasts, and location-based data.
🚀 Features
🌍 Real-time Weather Data (temperature, humidity, wind speed, etc.)
📍 Location-based Search using GPS or manual city input
☀️ Dynamic Backgrounds & Icons that change with weather conditions
🌙 Dark / Light Mode support
🕐 7-Day Forecast view (optional enhancement)
💾 Offline Caching of last fetched data using shared_preferences
🧩 Tech Stack
Framework: Flutter (Dart)
API: OpenWeatherMap API
State Management: Provider / GetX / Bloc (choose one based on your implementation)
Local Storage: SharedPreferences or Hive
Packages Used:
http — for API requests
geolocator — to get user location
intl — for date/time formatting
flutter_spinkit — for loading animations
