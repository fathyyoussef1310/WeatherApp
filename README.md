🌤 Weather App - Flutter Project

Description:
A beautiful, responsive, and fully functional Weather App built with Flutter. It provides real-time weather updates, forecasts, and location-based weather data, with dynamic UI changes based on weather conditions.

🚀 Features

🌍 Real-time Weather Data

Temperature, humidity, wind speed, weather condition description.

Updates fetched from the OpenWeatherMap API.

📍 Location-based Search

Automatically fetch weather using GPS.

Manual city search option.

☀️ Dynamic Backgrounds & Icons

Backgrounds change depending on weather (sunny, rainy, cloudy, etc.).

Weather icons updated in real-time.

🌙 Dark / Light Mode

Supports system theme or user preference.

🕐 7-Day Forecast

Optional enhancement for showing extended forecast.

💾 Offline Caching

Stores last fetched weather data using shared_preferences for offline access.

🧩 Tech Stack

Framework: Flutter (Dart)

API: OpenWeatherMap API

State Management: Choose one:

Provider

GetX

Bloc

Local Storage: SharedPreferences or Hive
